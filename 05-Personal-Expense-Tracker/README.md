# 💰 Personal Expense Tracker

A simple Python project that helps users keep track of their expenses and manage their remaining balance through an interactive terminal menu.

This project is part of my **Python Project Challenges**, where I'm learning Python through practical projects and improving my programming skills one step at a time.

## ✨ Features

- Enter an initial balance.
- Add new expenses.
- View all recorded expenses.
- Calculate total expenses.
- Check the remaining balance.
- Simple interactive terminal menu.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python expense_tracker.py
   ```

4. Follow the instructions displayed in your terminal.
