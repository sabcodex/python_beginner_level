# 📦 Simple Inventory System

A beginner-friendly Python project that allows users to manage a small product inventory through an interactive menu.

Add products, view available stock, search for specific items, and delete products easily.

This project is part of my Python Project Challenges, where I learn programming by building practical projects step by step.

## ✨ Features

- Add new products.
- Store product names, prices, and quantities.
- Display all available products.
- Search for a product by name.
- Delete products from the inventory.
- Interactive menu with multiple options.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the program:

   ```bash
   python inventory_system.py
   ```

5. Choose an option from the menu and follow the instructions.

- Searching for information.

To practice Python data structures and build a simple system that demonstrates how product inventory can be managed.
