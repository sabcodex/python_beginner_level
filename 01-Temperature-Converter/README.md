# 🌡️ Temperature Converter

A simple Python project that allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin**.

This project is part of my **Python Project Challenges**, a personal learning journey where I build small projects to practice Python fundamentals, improve my problem-solving skills, and gain confidence through hands-on experience.

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Simple interactive menu.
- Display conversion results with two decimal places.
- Easy-to-use terminal interface.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python temperature_converter.py
   ```

4. Follow the instructions displayed in your terminal.
