# 📒 Contact Book

A simple Python project that allows users to store, organize, search, and manage contact information through an interactive terminal menu.

This project is part of my **Python Project Challenges**, where I'm learning Python through practical projects and improving my programming skills one step at a time.

## ✨ Features

- Add new contacts.
- Store names, phone numbers, and email addresses.
- View all saved contacts.
- Search for contacts by name.
- Delete existing contacts.
- Simple interactive terminal menu.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python contact_book.py
   ```

4. Follow the instructions displayed in your terminal.
