# 📝 Text File Analyzer

A beginner-friendly Python project that reads a text file and analyzes its content. It calculates the number of words, characters, and lines in a simple and interactive way.

This project is part of my Python Project Challenges, where I practice programming through small projects and gradually improve my skills.

## ✨ Features

- Read text from a `.txt` file.
- Count the total number of words.
- Count the total number of characters.
- Count the total number of lines.
- Handle missing files with a simple error message.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Make sure Python is installed.
2. Place `text_file_analyzer.py` and your `.txt` file in the same folder.
3. Open a terminal in that folder.
4. Run:

   ```bash
   python text_file_analyzer.py
   ```

5. Enter the name of your text file when asked.

## 📚 What I Learned

- Opening and reading text files.
- Using `with open()`.
- Counting words, characters, and lines.
- Working with strings and lists.
- Handling errors using `try` and `except`.

## 🎯 Project Goal

To understand basic file handling in Python and learn how to extract useful information from text files.
