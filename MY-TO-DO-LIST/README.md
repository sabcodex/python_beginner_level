# 📝 To-Do List

A simple Python project that helps users organize their daily tasks through an interactive menu. Users can add new tasks, view their lists, mark tasks as completed, and delete tasks.

This project is part of my **Python Project Challenges**, where I'm learning Python through practical projects and improving my programming skills one step at a time.

## ✨ Features

- Add new tasks.
- View all saved tasks.
- Mark tasks as completed.
- Delete tasks.
- Interactive terminal menu.
- Simple and beginner-friendly interface.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python todo_list.py
   ```

4. Follow the instructions displayed in your terminal.
