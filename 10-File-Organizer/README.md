# 📁 File Organizer

A beginner-friendly Python project that automatically organizes files into different folders based on their extensions.

Instead of sorting files manually, this program scans a selected folder, identifies file types, creates the necessary folders, and moves files into their corresponding categories.

This project is part of my Python Project Challenges, where I develop my programming skills through practical projects.

## ✨ Features

- Scan a selected folder.
- Identify files by their extensions.
- Automatically create category folders.
- Organize images, documents, videos, and audio files.
- Move unknown file types into an `Others` folder.
- Check whether the selected folder exists.

## 🛠️ Built With

- Python 🐍
- `os` module
- `shutil` module

## 🚀 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   ```bash
   python file_organizer.py
   ```

5. Enter the path of the folder you want to organize.

**Note:** Test the program on a folder containing copies of your files first, because it moves files from their original locations.
