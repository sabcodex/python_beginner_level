# 🧮 Simple Calculator

A beginner-friendly Python project that performs basic mathematical operations. It allows users to enter two numbers, choose an operation, and get the result instantly.

This project is part of my **Python Project Challenges**, where I'm learning Python through practical exercises and small projects.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero.
- Simple interactive menu.
- Supports decimal numbers.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python simple_calculator.py
   ```

4. Follow the instructions displayed in your terminal.
