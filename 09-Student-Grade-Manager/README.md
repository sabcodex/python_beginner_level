# 🎓 Student Grade Manager

A beginner-friendly Python project designed to manage student information and academic grades through an interactive menu.

Add students, record their grades, calculate averages, and check whether they have passed or failed.

This project is part of my Python Project Challenges, where I develop my programming skills through practical projects.

## ✨ Features

- Add new students.
- Record three grades for each student.
- Display all registered students.
- Search for a student by name.
- Calculate student averages.
- Check pass or fail status.
- Interactive menu system.

## 🛠️ Built With

- Python 🐍

## 🚀 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the program:

   ```bash
   python student_grade_manager.py
   ```

5. Follow the menu instructions.

## 📚 What I Learned

- Working with lists and dictionaries.
- Storing multiple grades.
- Calculating averages using `sum()` and `len()`.
- Searching for students.
- Using conditional statements.
- Organizing information with Python.

## 🎯 Project Goal

To practice Python data structures, calculations, and conditional logic by building a simple academic grade management system.
