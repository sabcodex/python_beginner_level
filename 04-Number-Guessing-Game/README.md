# 🎲 Number Guessing Game

A fun and simple Python game where the computer randomly selects a number between 1 and 100, and the player has to guess it.

The program provides hints after each attempt, helping the player figure out whether their guess is too high or too low.

This project is part of my **Python Project Challenges**, where I'm learning Python through practical projects and improving my programming skills one step at a time.

## ✨ Features

- Random number generation.
- Number guessing between 1 and 100.
- Helpful hints after each guess.
- Tracks the number of attempts.
- Congratulates the player after finding the correct number.
- Simple interactive gameplay.

## 🛠️ Built With

- Python 🐍
- Random module

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash

   ```

4. Start guessing and have fun!
